## 🌐 ¿Cómo subirlo a GitHub y proyectarlo con GitHub Pages?

1. **Crea un nuevo repositorio en tu GitHub:**
   - Nombre sugerido: `liderazgo-equipo1`
   - Déjalo como **Público**.

2. **Sube los archivos desde tu terminal:**
   ```bash
   git remote add origin https://github.com/TU_USUARIO/liderazgo-equipo1.git
   git branch -M main
   git push -u origin main
   ```

3. **Activar GitHub Pages (1 clic):**
   - Ve a tu repositorio en GitHub ➔ **Settings** (Configuración) ➔ **Pages**.
   - En **Branch**, selecciona `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**.
   - En 30 segundos te dará un link público como: `https://TU_USUARIO.github.io/liderazgo-equipo1/`

4. **¡Listo para proyectar!**
   - Abre ese link en la computadora conectada al proyector.
   - Presiona `F11` (o pantalla completa) en tu navegador y disfruta de la exposición.
